# Sabor Casero 🍅

Sitio web escolar sobre comida y recetas, realizado con HTML y CSS.

## Secciones
- **Inicio** (`index.html`): presentación del sitio y acceso a las demás secciones.
- **Recetas** (`recetas.html`): recetas fáciles para almuerzos y cenas.
- **Desayunos** (`desayunos.html`): ideas simples para empezar el día.
- **Consejos** (`consejos.html`): trucos básicos para cocinar.

## Archivos
Los cuatro archivos HTML están conectados entre sí y comparten la hoja de estilos `estilos.css), para mantener la misma estética en todo el sitio.

## Cómo verlo
Abrí `index.html` en un navegador. Las fotografías se cargan desde Unsplash, por lo que requieren conexión a internet.

## Publicación
Para activar GitHub Pages: entrá en **Settings → Pages**, elegí **Deploy from a branch**, seleccioná la rama **main** y la carpeta **/(root)**, y guardá los cambios.
