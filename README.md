# Sabor Casero 🍅
## Secciones del sitio
- **Inicio:** presentación de la página.
- **Recetas:** ejemplos de comidas fáciles.
- **Consejos:** recomendaciones sencillas para cocinar.
- **Contacto:** información sobre el proyecto.
## Archivos
El sitio tiene cuatro páginas HTML conectadas mediante enlaces. Todas utilizan la misma hoja de estilos llamada `estilos.css`, para mantener los mismos colores y el mismo diseño.
## Cómo abrirlo
Abrí el archivo `index.html` con un navegador. Las imágenes se cargan desde internet.
## Colores
Se utilizan verde, naranja, crema, blanco y gris.
